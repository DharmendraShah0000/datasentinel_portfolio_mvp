# Android / iOS roadmap
- React Native + Expo client consuming the same REST API.
- Auth: OIDC authorization-code + PKCE, short-lived access tokens and secure refresh-token storage (Keychain/Android Keystore); backend tenant-scoped authorization.
- Offline: SQLite cache for recently viewed dataset profiles; upload queue with resumable status and clear conflict/error UX.
- Mobile UX: camera/document share-sheet CSV import, compact profile summaries, chart drilldowns, accessible color-independent quality states.
- Notifications: opt-in push for scheduled monitor alerts once monitors and notification service exist.
- Android: EAS build, test internal track, privacy/data-safety declarations, signed app bundle and Play Console listing.
- iOS: EAS build, TestFlight, App Store privacy nutrition labels, signing/provisioning, review guidelines and store listing.
This repository does not contain a native app and is not app-store ready.
